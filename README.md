# HereList

**Открытый музыкальный клиент YouTube Music для Windows и Android, разработанный на Kotlin Multiplatform.**

HereList создаётся как единое приложение для компьютеров и мобильных устройств с собственным интерфейсом на Material Design 3.

> **Статус проекта:** ранняя разработка. Сейчас в репозитории находится начальный каркас приложения и демонстрационный интерфейс. Воспроизведение и подключение к музыкальному сервису ещё не реализованы.

## Возможности в планах

- Поиск треков, альбомов и исполнителей
- Воспроизведение музыки и управление очередью
- Медиатека, избранное, плейлисты и история
- Тексты песен, включая синхронизированные тексты LRC
- Поддерживаемые функции персонализации и синхронизации через аккаунт Google
- Версии для Windows и Android
- Поддержка Linux на более позднем этапе

Офлайн-воспроизведение и загрузка будут реализованы только для аудио, которое приложению разрешено сохранять и воспроизводить без подключения к интернету. Проект не предназначен для обхода DRM, механизмов контроля доступа или ограничений подписки YouTube Music.

- `composeApp` — общий интерфейс и код для разных платформ
- `androidApp` — приложение для Android
- `desktopApp` — приложение для Windows и других настольных систем

## Сборка

Для разработки понадобится Android Studio с поддержкой Kotlin Multiplatform и JDK 17.

### Android

Открой репозиторий в Android Studio и дождись синхронизации Gradle. Gradle Wrapper уже включён в репозиторий.

Или выполни в терминале Windows:

```powershell
.\gradlew.bat :androidApp:assembleDebug
```

APK после успешной сборки появится в:

`androidApp/build/outputs/apk/debug/androidApp-debug.apk`

### Windows

Для запуска настольной версии выполни:

```powershell
.\gradlew.bat :desktopApp:run
```

Gradle Wrapper автоматически загрузит Gradle 8.13 при первом запуске.
